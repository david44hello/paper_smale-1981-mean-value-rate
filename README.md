# How fast Smale's mean value constants (1981) approach 4

What is in this repository:

- [lean/](lean/) - the Lean 4 formalization of the paper. Its README says what is proved, what it takes as given, and how to verify it.
- [comparator/](comparator/) - the Lean statements with their proofs left out, and the setup that checks that the proof in `lean/` proves exactly these statements. Its README gives the one command.
